# Bot A handoff — optional free integrations (API v1)

Backend implementation and OpenAPI are ready. These additions do not change any existing AI workflow path or response. Codex has not changed `frontend/`. There is no Bot A agent session connected to this chat; this document is the shared integration handoff for the frontend owner.

All calls go to the Maximus backend. Never call provider APIs directly from the browser, and never send provider credentials to the frontend. Job and curated learning routes deliberately do not require a learner session or signup.

## Job Explorer

`GET /api/v1/jobs/search?q=python&provider=both&limit=20`

- `q`: at most 100 characters; `provider`: `both` (default), `himalayas`, or `remotive`; `limit`: 1–40.
- Response: `{jobs, providers, returned_count, note}`. Each job has `id`, `title`, `company`, optional `location`, `employment_type`, `published_at`, `expires_at`, plain-text `summary`, `tags`, `application_url`, and `sources`.
- Render each source's visible name and `source_url` link. For deduplicated listings render **all** source links. The main Apply action uses `application_url` exactly as supplied; each entry in `sources` also retains that provider's original application URL. Remotive supplies its own job page as the original apply link; do not replace it with a guessed company/ATS link. Preserve Himalayas `applicationLink` unchanged, including query parameters.
- Do not hide public job listings behind onboarding, signup or email collection. Do not republish these listings to third-party job boards, feeds, Google Jobs or LinkedIn, or emit syndicated JobPosting structured data. Display source attribution and retain provider delay/staleness notices. No provider endorsement is implied.
- `providers` is a list of `{provider, status, cached, fetched_at, detail, retry_after_seconds}`. States are `ok`, `error`, `disabled`, `not_configured`, `rate_limited`. Show a provider-specific unavailable/rate-limit banner while still rendering successful results. HTTP 200 with empty jobs and provider errors is a valid partial/unavailable result, not proof that no jobs exist.
- Himalayas fetches one search page (up to 20 records), cached 15 minutes. Expired listings are removed at response time. Remotive fetches up to 200 recent jobs once per six hours and searches that cached subset locally; it is not an exhaustive search. Remotive's API delays listings by 24 hours. Duplicate canonical application URLs are merged; matching company/title/location records are merged across providers, retaining attribution.
- No fabricated match/readiness scores or inferred required skills are supplied. Tags are source-provided categories/tags, not a validated assessment of job requirements. Do not map these to the frontend's old `matchScore`, `missingSkills` or `requiredSkills` placeholder fields as if assessed.

## Learning Hub and roadmap resources

`GET /api/v1/learning/resources?q=python` returns `{resources, providers}` from a curated official catalog. Use an empty query to show all five entries. Catalog links are freeCodeCamp Python and Responsive Web Design, MIT OCW 6.0001 Python, the Python Tutorial and MDN Learn. Metadata is manually curated, not generated by a model. `reviewed_on` records the catalog review date; it is not a completion or accreditation claim. These links do not promise certificates, durations, current video availability or learner progress.

Add `include_youtube=true` with a nonempty query to include real videos from the existing backend-only YouTube key. Or call `GET /api/v1/learning/youtube?q=python` for videos alone. A failed or unconfigured YouTube provider leaves the official catalog usable. Querying with a roadmap step's `skill` connects resources to the existing roadmap without making external services mandatory for generation.

Resource fields: `id`, `title`, `provider`, `url`, `kind` (`course`, `documentation`, `video`), `topics`, `provenance` (`curated_official`, `youtube_api`), optional `reviewed_on` and `channel`. Render URLs as original external links. YouTube search is cached for one hour; use deliberate searches, not polling, to conserve quota. YouTube entries are search results, not an endorsement or promise of educational accuracy.

## Public GitHub evidence

`GET /api/v1/integrations/github/psf/requests?paths=src/requests/api.py&paths=README.md`

Response: `{repository, files, providers}`. Omit paths for metadata only. `repository` may be null on failure; otherwise it includes source URL, language, stars, forks, branch, description, license and pushed timestamp. These are attributable repository facts; they do not verify learner authorship or skill.

Select at most three relative source/documentation paths, at most 64 KiB each. Each file returns `{path, url, sha, content, status, detail}`; statuses are `ok`, `error`, `too_large`, `unsupported`. Render content **only as escaped text**, never execute it or insert it as HTML. Preserve blob SHA and source link as evidence provenance. Files are fetched from the default branch at retrieval time; SHAs identify the actual individual blobs. No repository clone, dependency install, code execution, author verification or AI skill inference occurs.

GitHub calls remain public-only and now use the configured backend GITHUB_TOKEN when available. No token is exposed to the browser. Private repos, arbitrary URLs, path traversal, hidden files, credentials and key files are rejected. Metadata can succeed while selected files fail: keep available metadata and show per-file/provider states. Public unauthenticated API rate limits may be shared with other users on the deployment IP.

External requests have an 8-second total deadline by default (GitHub requests allow up to 16 seconds) and bounded responses. Different job providers run concurrently. GitHub metadata plus up to three files is bounded but sequential (allow a 45-second client timeout). Use loading/empty/error/partial-success states; do not fake data. All features can be independently disabled through backend configuration.
